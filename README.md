# 🔮 Thai Daily Horoscope Web App (เว็บแอปดูดวงรายวันลัคนาราศีและดวงจร)

เว็บแอปพลิเคชันดูดวงรายวันส่วนบุคคล (Personalized Daily Horoscope) ที่คำนวณตำแหน่งดวงดาวอย่างแม่นยำตามหลัก **โหราศาสตร์ไทยระบบคัมภีร์สุริยยาตร์ (อันโตนาทีสามัญ)** และ **ระบบนิรายนะวิธี (Sidereal Zodiac - ลาหิรี Ayanamsa)** ตามมาตรฐานโหราศาสตร์ไทย

นำ **ดวงลัคนาเดิม (Natal Chart)** จากเวลาตกฟากและพิกัดละติจูด-ลองจิจูดของ 77 จังหวัดในประเทศไทย มาวิเคราะห์ร่วมกับ **ตำแหน่งดาวจรประจำวัน (Transit Chart)** เพื่อสรุปคำพยากรณ์รายวันแยกเป็นหมวดหมู่อย่างกระชับ อ่านง่าย นำไปใช้ได้ทันที

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **ผูกดวงลัคนาเดิม (Natal Chart)**:
   - ระบุ วัน/เดือน/ปีเกิด, เวลาเกิด (เวลาตกฟาก), และจังหวัดที่เกิด
   - คำนวณอันโตนาที / Sidereal RAMC เพื่อหาจุดตัดลัคนา (Ascendant) ใน 12 ราศีอย่างแม่นยำ
   - แสดงนักษัตรฤกษ์กำเนิด (27 ฤกษ์ เช่น ทลิทโท, มหัทธโน, เทวี, ราชา ฯลฯ)
   - คำนวณตำแหน่งดาวเดิม ๑ (อาทิตย์) ถึง ๐ (มฤตยู) ใน 12 ภพ (ตนุ..วินาศ)

2. **คำนวณดวงดาวจรรายวัน (Transit Chart)**:
   - คำนวณตำแหน่งดาวจริงบนท้องฟ้าในแต่ละวัน (อาทิตย์ ๑, จันทร์ ๒, อังคาร ๓, พุธ ๔, พฤหัสบดี ๕, ศุกร์ ๖, เสาร์ ๗, ราหู ๘, เกตุ ๙, มฤตยู ๐)
   - วิเคราะห์ดาวจรเข้าภพ (12 Bhavas) และมุมสัมพันธ์กับดาวเดิม (ทับ, เล็ง, ตรีโกณ, โยค)
   - จับตาเป็นพิเศษที่ **ดาวจันทร์ (๒)** ซึ่งโคจรเร็วที่สุด (เปลี่ยนราศีทุก 2.5 วัน) ในฐานะตัวจุดชนวนเหตุการณ์และอารมณ์ประจำวัน (Daily Trigger)

3. **ผังจักรราศีไทย (Thai Duang Wheel 12 ช่อง)**:
   - แสดงผังดวง 12 ราศี พร้อมระบุจุดลัคนา (ลั)
   - แสดงดาวกำเนิด (สีฟ้า) และดาวจร (สีส้มทอง) ซ้อนกันในแต่ละราศี
   - คลิกเลือกราศีเพื่อดูความหมายของภพและดาวจรที่ส่งกำลัง

4. **สรุปผลการพยากรณ์แยกหมวดหมู่ (Categorized Summary)**:
   - 🌟 **ภาพรวมประจำวัน**: คะแนนพลังงานดวง (Energy Score 0-100%), ดัชนีดวง และบทสรุป
   - 💼 **การงานและธุรกิจ**: วิเคราะห์จากภพกัมมะ ตนุ ศุภะ และดาว ๑, ๓, ๕
   - 💰 **การเงินและโชคลาภ**: วิเคราะห์จากภพกดุมภะ ลาภะ และดาว ๒, ๔, ๕, ๖, ๘
   - ❤️ **ความรักและความสัมพันธ์**: วิเคราะห์จากภพปัตนิ ปุตตะ และดาว ๖, ๒
   - 🛡️ **สุขภาพและข้อควรระวัง**: วิเคราะห์จากภพอริ มรณะ วินาศ และดาว ๗, ๘, ๓, ๐
   - 🔮 **เกร็ดมงคลเสริมดวง (Daily Lucky Boosters)**:
     - สีเสื้อมงคลประจำวัน (ทักษาจร: เสริมงาน, เสริมเงิน, เสริมเสน่ห์)
     - สีกาลกิณีที่ควรเลี่ยงในวันนี้
     - เลขเด่นนำโชคประจำวัน
     - ฤกษ์มงคลประจำวัน
     - ทิศมงคลนำโชค

5. **ระบบความสะดวกเพิ่มเติม**:
   - บันทึกและสลับโปรไฟล์ดวงชะตาได้หลายคน (LocalStorage)
   - ปรับเปลี่ยนวันที่ดูดวง (ดูดวงวันนี้, เมื่อวาน, พรุ่งนี้ หรือเลือกวันใดๆ)
   - ปุ่มคัดลอกสรุปดวง (Share) ส่งต่อใน LINE / โซเชียลมีเดียได้ทันที
   - หน้าต่างตรวจพิกัดดาวดาราศาสตร์ (Astronomical Ephemeris Modal)

## 🚀 วิธีเปิดใช้งานและรันโปรเจกต์ (Running the App)

โปรเจกต์นี้ทำงานด้วย **Python Standard Library (Pure Python)** โดยไม่ต้องลงแพ็กเกจภายนอกใดๆ เพิ่มเติม

### รันบนเครื่องตนเอง (Local Development):
เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:
```bash
python -X utf8 app.py
```
- ระบบจะเปิดเบราว์เซอร์และเข้าสู่ `http://localhost:5173` ให้โดยอัตโนมัติ

## 🌐 การ Deploy ขึ้นเว็บด้วย Vercel

โปรเจกต์พร้อมสำหรับการ Deploy ขึ้น Vercel ทันที โดยใช้สถาปัตยกรรม **Static Frontend + Python Serverless Function**:

1. **นำโค้ดขึ้น GitHub Repository ของคุณ**:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. **เปิดหน้า Vercel**:
   - ไปที่ [https://vercel.com/new](https://vercel.com/new)
   - ล็อกอินด้วยบัญชี GitHub ของคุณ
   - กดปุ่ม **Import** ที่ repository นี้
3. **กด Deploy**:
   - Vercel จะตรวจพบ `vercel.json`, `index.html` และ Serverless Function `api/index.py` อัตโนมัติ
   - รอเพียงไม่กี่วินาที จะได้รับ URL สด เช่น `https://your-project.vercel.app` พร้อมใช้งานทันทีทั่วโลก!
